# 🏆 CAN 2025 — Ticket Reservation

Application web de démonstration permettant de gérer des réservations de billets pour la CAN 2025 au Maroc.

## 🌐 Démo en ligne

🔗 [Voir le projet](https://riyadlmsaouri-code.github.io/CAN2025-Ticket-Reservation/)

## ✨ Fonctionnalités

- Réservation de billets selon le stade et la date
- Calcul automatique du montant total
- Affichage de la liste des réservations
- Sauvegarde locale des réservations avec LocalStorage
- Interface responsive

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🚀 Utilisation

1. Ouvrir la démo en ligne.
2. Renseigner le nom, le stade, la date et le nombre de billets.
3. Cliquer sur Réserver.
4. Consulter les réservations enregistrées.
